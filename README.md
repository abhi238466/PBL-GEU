## 📌 About

**PBL-GEU** is a centralized repository for managing and organizing the **Project-Based Learning (PBL)** projects of students at **Graphic Era University (GEU)**.

Each PBL group is assigned a dedicated **country folder** in this repository.  
The complete project work of the respective group will be maintained inside its assigned folder.

This repository helps maintain a structured and organized environment for **project development, collaboration, and progress monitoring**.
